# 🎓 Alumni Portal

A comprehensive web-based platform designed to bridge the gap between current students and alumni. This portal serves as a hub for mentorship, career guidance, and networking.

## 🌟 Key Features
* **Alumni Speaks:** A dedicated section for alumni to share success stories and career journeys.
* **Webinar Integration:** Stay updated with upcoming sessions and technical talks hosted by industry experts.
* **Mentorship & Reference:** A system for students to request job references and career assistance directly from alumni.
* **Motivation Hub:** Inspiring content to keep students focused on their academic and professional goals.

## 🛠 Tech Stack
* **Frontend:** HTML5, CSS3 (Static Web Pages)
* **Tools:** GitHub Pages (for hosting)

## 📂 Project Structure
Below is a breakdown of the core modules included in this portal:
* **`index.html`** - The primary landing page and entry point.
* **`alumni_assist.html`** - Support and guidance module.
* **`alumni_contact.html`** - Networking and communication page.
* **`alumni_reference.html`** - Career reference request system.
* **`alumni_speaks.html`** - Success stories and alumni feedback.
* **`webinar.html`** - Event scheduling and technical session details.
* **`motivation.html`** - Inspirational content for students.
* **`events.html`** - Overview of portal activities.
